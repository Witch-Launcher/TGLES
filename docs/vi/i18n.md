# Thêm ngôn ngữ mới

Docs dùng mô hình **một thư mục một ngôn ngữ** của Docsify, nên thêm ngôn
ngữ mới không cần sửa code — chỉ thêm file.

## Các bước (ví dụ thêm tiếng Nhật `ja`)

1. Copy toàn bộ thư mục `docs/en/` thành `docs/ja/` (giữ nguyên tên file).
2. Dịch nội dung từng file `.md` trong `docs/ja/`, **giữ nguyên**:
    - tên file và cấu trúc heading,
    - badge trạng thái chữ `[PASS]` / `[FAIL]` / `[WARN]`,
    - link nội bộ (đổi `/en/` thành `/ja/`).
3. Sửa `docs/ja/_navbar.md` và `docs/ja/_sidebar.md`: đổi label sang tiếng
   mới, thêm link ngôn ngữ mới vào cả 3 navbar (`_navbar.md`, `vi/_navbar.md`,
   `en/_navbar.md`, và mọi navbar ngôn ngữ khác).
4. Thêm placeholder/noData trong `docs/index.html`:
   `'/ja/': '...'` ở cả hai object `placeholder` và `noData`.
5. Thêm vào danh sách ngôn ngữ ở `docs/README.md` (landing).
6. Chạy thử: `docsify serve docs`, mở `/ja/` kiểm tra sidebar, navbar,
   search, cover.

## Quy ước

- Docs thuần chữ, không dùng sticker hay ảnh minh họa; trạng thái trong
  bảng dùng badge chữ `[PASS]` / `[FAIL]` / `[WARN]`.
- Không hardcode tên ngôn ngữ trong `index.html` ngoài 2 object search —
  mọi thứ khác đọc từ folder.
- Mỗi PR thêm ngôn ngữ phải preview đủ 3 route: `/`, `/xx/`, `/xx/minecraft`.
